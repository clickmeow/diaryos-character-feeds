DiaryOS Feed Editor

Local visual editor for character feed timelines. Start it with python shared\serve_editor.py.
Overview
Reverse-sync contract: edit characters/<id>/feed.json as the source of truth. Saving also writes feed.csv. Uploaded images go to characters/<id>/images/ and are named from post_id. Future Ren'Py sync should read feed.json, generate an import table or sns_imported_data.rpy, then run a game git backup and Ren'Py lint.
